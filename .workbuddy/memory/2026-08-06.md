### 关键技术笔记
- matplotlib mathtext 在 raw string 中：`\times` 会触发 Python SyntaxWarning 但不影响渲染；更安全写法是 `{times}`
- `FancyBboxPatch` 对象没有 `_ax` 属性，传 ax 给辅助函数需显式传入
- `tight_layout()` 与 inset_axes 共存时会有 warning，结果通常可接受
